Colour systems — four closed sets, never crossed
{{ grp.title }}

{{ sw.token }}
{{ sw.meaning }}
Rule. Status, content-type and accent are three separate colour token sets. A colour from one never appears in another's role: the accent (violet {{ dsAccentHex }}) is never a status colour and never fills a badge; status violet ("Processing", automated) never moves to buttons or links. They sit near each other in hue by coincidence, not by relation. Access is not a colour set — it has no token here because it carries no colour at all: Owner through Viewer render in identical text style, see badge-access-* below.

--font-display (Mark Pro) — page headers + approved display uses
{{ t.token }} Aa 123 {{ t.usage }}
Rule. Mark Pro is used for page H1s (standardized at 24px/700, one heading style everywhere) plus the wizard step headline, wizard completion headline, and two empty-state hero lines — all at weight 700 (no true Semibold file exists; Medium reads too light at display sizes). Entity names, labels, numbers, and table headers stay Inter. No hardcoded family: every text style routes through var(--font-ui) or var(--font-display).
